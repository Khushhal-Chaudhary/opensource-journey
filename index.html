LESSON 01

What is Open Source?

Open-source software is software whose source code is made available under a license that allows people to use, study, modify and share it according to the license terms.

Why is it important?

  • Developers can collaborate on projects.
  • People can learn from existing source code.
  • Contributors can suggest improvements.
  • Communities can build software together.
Example

Imagine a developer creates a useful website and publishes its source code on GitHub under an open-source license. Other developers can study it and contribute improvements within the license terms.

LESSON 02

Understanding Git and GitHub

Git is a version control system that helps developers track changes in their code.

GitHub is an online platform where developers host Git repositories and collaborate on projects.

Important GitHub terms

  • Repository: A place to store and manage project files.
  • Fork: Your own copy of someone else's repository on GitHub.
  • Clone: Copy a repository onto your computer.
  • Branch: An independent line of development.
  • Commit: A recorded change in a repository.
  • Pull Request: A proposal to merge changes into another branch.
Remember this

Git manages changes. GitHub makes it easier to host projects and collaborate online.

LESSON 03

Make your first contribution

You don't need to be an expert programmer to begin contributing to open source. Start by understanding a project and its guidelines.

Basic contribution workflow

  1. Find an open-source project.
  2. Read its README and contribution guidelines.
  3. Find an issue you can work on.
  4. Fork the repository.
  5. Clone your fork.
  6. Create a new branch.
  7. Make and test your changes.
  8. Commit and push your changes.
  9. Open a pull request.
Practice resource
