# OpenSource Journey – Development Log

## 1. Project Overview

OpenSource Journey is a beginner-friendly website designed to help students understand open-source development, Git, and GitHub.

The project was created as part of my learning journey and practical development experience.

## 2. Project Objectives

- Understand the fundamentals of open source.
- Learn Git and GitHub.
- Build a website using HTML, CSS, and JavaScript.
- Track personal learning progress.
- Document development challenges and improvements.

## 3. Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Interactive features |
| Local Storage | Saving progress and journal entries |
| Git | Version control |
| GitHub | Hosting project source code |
