# OpenSource Journey 🚀

**A beginner-friendly platform to learn Open Source, Git, and GitHub while documenting my own learning journey.**

## 📌 About the Project

OpenSource Journey is a learning platform designed to help beginners understand open-source development step by step.

I created this project as part of my learning journey to apply my HTML, CSS, and JavaScript knowledge while using AI tools as development assistance.

## ✨ Features

- **Learning Library:** Beginner-friendly lessons about open source, Git, and GitHub.
- **Interactive Roadmap:** Track completed learning tasks.
- **Progress Tracking:** View learning progress as a percentage.
- **Personal Learning Journal:** Add and manage learning experiences.
- **Local Storage:** Save progress and journal entries in the browser.
- **Responsive Design:** Access the website on different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Git and GitHub
- AI-assisted development

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/Khushhal-Chaudhary/opensource-journey.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
